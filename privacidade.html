Política de Privacidade

Quem é o controlador

O GK Hub, com contato pelo e-mail assessoriaphstudios@gmail.com. O GK Hub é uma plataforma de análise de desempenho de goleiros(as) de futsal e beach soccer.

Dados que tratamos

Dados do clube; dados de atletas (nome, data de nascimento, dados físicos, posição e foto opcional) e dados de desempenho (scouts, partidas, notas, lesões e plano individual). Não solicitamos dados sensíveis além dos necessários à finalidade esportiva.

Para que usamos

Registrar e analisar o desempenho esportivo dos(as) atletas, para uso da comissão técnica do clube.

Base legal e atletas menores de idade

O tratamento é feito mediante consentimento. Para atletas menores de idade, o consentimento é dado e registrado pelo(a) responsável legal no cadastro do(a) atleta, com nome do responsável e data.

Com quem compartilhamos

Os dados ficam no aparelho do usuário e são sincronizados em nuvem (Google Firebase) entre os dispositivos do mesmo clube. Os dados de clubes diferentes nunca se misturam. Os recursos de inteligência artificial usam a API do Google (Gemini) apenas com dados de desempenho, sem identificar o(a) atleta além do necessário. Não vendemos dados.

Seus direitos

Acesso, correção, portabilidade (exportar em JSON ou planilha) e eliminação (direito ao esquecimento). Podem ser exercidos no próprio aplicativo, em Clube → Privacidade e LGPD, ou pelo e-mail acima.

Segurança e retenção

Os dados são isolados por clube no servidor; a sessão e o segredo de verificação em duas etapas nunca saem do aparelho; as ações ficam registradas na Auditoria. Os dados são mantidos enquanto o clube usar o serviço e podem ser apagados a qualquer momento pelo titular ou responsável.

Encarregado pelo tratamento de dados (DPO)

Solicitações sobre dados pessoais podem ser feitas pelo e-mail assessoriaphstudios@gmail.com, que responde em até 15 dias.

  2. O(a) usuário(a) é responsável pela veracidade dos dados inseridos e por obter o consentimento dos titulares — ou dos responsáveis legais, no caso de menores.
  3. Assinatura: o uso é mediante plano pago, conforme o plano contratado. O período de teste, quando houver, é informado no cadastro.
  4. O serviço é fornecido “como está”; buscamos disponibilidade e precisão, mas não garantimos ausência de falhas. Faça backups — o aplicativo oferece exportação.
