Backup e Dados

Os dados ficam salvos neste navegador. Faça backup para não perder nada ao trocar de aparelho ou limpar o cache.

Importar/restaurar substitui os dados atuais. Por segurança, o backup não inclui sua sessão de login, o 2FA nem a chave do clube. Para levar tudo (inclusive reconectar a nuvem) use o Backup protegido — ele é criptografado por senha.
Histórico de backups (nuvem)
Um backup é salvo automaticamente na nuvem 1x por dia. Mantemos os últimos 10 — dá para restaurar qualquer um.
—
Código do clube (nuvem)
Cada clube tem um código próprio — os dados de clubes diferentes nunca se misturam. Membros do mesmo clube devem usar o mesmo código. Compartilhe este código só com a sua comissão técnica.
Privacidade e LGPD

Como o sistema trata dados de atletas (inclusive menores de idade). Marque o consentimento no cadastro do(a) goleiro(a). Aqui você exerce os direitos do titular:

• Consentimento: registrado por atleta no cadastro (data e responsável).
• Portabilidade: exporte todos os dados da atleta em JSON.
• Eliminação: apaga cadastro, scouts, lesões, PID e análises da atleta, localmente e na nuvem.
• Segurança: sessão e 2FA nunca saem do dispositivo; ações ficam registradas na Auditoria.
